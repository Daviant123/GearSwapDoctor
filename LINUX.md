GearSwap Doctor for Linux

Nothing to install. Unpack this, then double-click GearSwap-Doctor, or in a terminal:

    ./GearSwap-Doctor

It keeps its settings and backups in ~/.local/share/GearSwap Doctor. It looks for Windower 4 in the usual Wine, Proton, Lutris and
Bottles folders; if it can't find it, it asks once: pick the folder that has addons and plugins in it.

If double-clicking does nothing, your file manager may be set to open programs as text: use the terminal line above, or right-click
the file > Run. It needs a normal desktop (X11 or XWayland) and a Linux about as new as Ubuntu 22.04.
